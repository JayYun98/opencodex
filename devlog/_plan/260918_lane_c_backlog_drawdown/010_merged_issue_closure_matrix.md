## The one row that is not a clean close

#4857 is the only pair where the merged fix does not reach the reported configuration.
#4891 is honest about this in its own text — it says the common Responses path keeps the
zeroed first frame "by design rather than by accident" — but the issue was filed from that
path, so the delivered scope and the reported symptom do not overlap. The two options the
issue offered were an early real value (implemented, conditional on the upstream) and a
synthetic delta once usage is known (not implemented). The second is what the reporter's
client would actually have consumed.
